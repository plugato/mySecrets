╔════════════════════════════════════════════════════════════════╗
║                  MAKEFILE - COMANDOS RÁPIDOS                   ║
╚════════════════════════════════════════════════════════════════╝

┌────────────────────────────────────────────────────────────────┐
│ 🚀 EXECUÇÃO                                                     │
├────────────────────────────────────────────────────────────────┤
│ make dev          → Executar (DevTools aberto)                 │
│ make start        → Executar (modo produção)                   │
│ make run          → Alias para 'make dev'                      │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 📦 BUILD                                                        │
├────────────────────────────────────────────────────────────────┤
│ make build        → Build TODAS as plataformas (demora!)       │
│ make build-linux  → Build Linux (AppImage) ⭐                   │
│ make build-win    → Build Windows (requer Wine)                │
│ make pack         → Empacota sem instalador (rápido)           │
│ make build-all    → clean + build-linux + build-win            │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 🔧 SETUP                                                        │
├────────────────────────────────────────────────────────────────┤
│ make install      → Instala dependências npm                   │
│ make reinstall    → Remove tudo e reinstala                    │
│ make icons        → Gera ícones temporários                    │
│ make setup        → Setup inicial completo                     │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 🧪 TESTES                                                       │
├────────────────────────────────────────────────────────────────┤
│ make test         → Executa testes                             │
│ make test-totp    → Testa geração TOTP/MFA                     │
│ make test-import  → Testa importação de MFA                    │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 🧹 LIMPEZA                                                      │
├────────────────────────────────────────────────────────────────┤
│ make clean        → Remove builds (dist/)                      │
│ make clean-all    → Remove TUDO (até node_modules)             │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 🌐 EXTENSÃO CHROME                                              │
├────────────────────────────────────────────────────────────────┤
│ make extension    → Prepara extensão                           │
│ make ext-icons    → Gera ícones da extensão                    │
│ make ext-pack     → Empacota extensão (.zip)                   │
│ make ext-install  → Mostra como instalar no Chrome             │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 📊 INFORMAÇÕES                                                  │
├────────────────────────────────────────────────────────────────┤
│ make status       → Status do projeto (estrutura, builds)      │
│ make version      → Versões (Node, npm, Electron)              │
│ make size         → Tamanho dos builds                         │
│ make docs         → Lista documentação disponível              │
│ make check        → Verifica problemas                         │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 🎯 COMANDOS COMBINADOS                                          │
├────────────────────────────────────────────────────────────────┤
│ make all          → install + icons + dev                      │
│ make quick        → clean + install + dev                      │
│ make setup        → Setup inicial do projeto                   │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 🐛 DEBUG                                                        │
├────────────────────────────────────────────────────────────────┤
│ make debug        → Executa com logs verbose                   │
│ make check        → Verifica instalação e problemas            │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ ❓ AJUDA                                                        │
├────────────────────────────────────────────────────────────────┤
│ make              → Mostra TODOS os comandos (colorido)        │
│ make help         → Mesmo que acima                            │
│ make shortcuts    → Atalhos de teclado                         │
└────────────────────────────────────────────────────────────────┘


╔════════════════════════════════════════════════════════════════╗
║                      FLUXO DE TRABALHO                         ║
╚════════════════════════════════════════════════════════════════╝

┌─ PRIMEIRA VEZ ─────────────────────────────────────────────────┐
│  1. make setup         → Instala tudo                          │
│  2. make dev           → Executa o app                         │
└────────────────────────────────────────────────────────────────┘

┌─ DESENVOLVIMENTO DIÁRIO ───────────────────────────────────────┐
│  1. make status        → Ver status                            │
│  2. make dev           → Executar                              │
│  3. (desenvolver...)                                           │
│  4. make test-totp     → Testar                                │
└────────────────────────────────────────────────────────────────┘

┌─ CRIAR RELEASE ────────────────────────────────────────────────┐
│  1. make clean         → Limpar builds antigos                 │
│  2. make build-linux   → Build AppImage                        │
│  3. make size          → Verificar tamanho                     │
└────────────────────────────────────────────────────────────────┘

┌─ PROBLEMAS? ───────────────────────────────────────────────────┐
│  1. make check         → Verificar instalação                  │
│  2. make quick         → Limpar e reinstalar                   │
│  3. make dev           → Executar novamente                    │
└────────────────────────────────────────────────────────────────┘

     make clean         → Limpar
     make quick         → Reinstalar tudo
