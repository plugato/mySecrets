Política de Privacidade — MySecrets

Última atualização: 1º de novembro de 2026

Esta política vale para o app desktop MySecrets e para a extensão MySecrets Autofill. O MySecrets é um gerenciador de senhas e códigos 2FA que guarda os dados num cofre criptografado no computador do próprio usuário. O desenvolvedor não opera servidores e não recebe nenhum dado dos usuários.

Cofre e senha mestra

  • Senhas, códigos 2FA e notas ficam num arquivo criptografado com AES-256-GCM, com chave derivada da senha mestra (PBKDF2-SHA256).
  • A senha mestra nunca é enviada a lugar nenhum e não pode ser recuperada pelo desenvolvedor.

Sincronização com o Google Drive (opcional)

Se o usuário clicar em "Entrar com Google", o app usa a API do Google Drive para guardar uma cópia do cofre no Drive do próprio usuário:

  • Permissões pedidas: drive.file (acesso apenas aos arquivos criados pelo próprio app, na pasta MySecrets), openid e email (para mostrar qual conta está conectada).
  • O que é enviado: somente o arquivo do cofre, já criptografado no computador antes do envio, e uma lista de identificadores aleatórios de itens apagados. O Google não consegue ler o conteúdo do cofre.
  • O que o app não faz: não lê, lista nem altera outros arquivos do Drive do usuário.
  • Onde ficam as credenciais: o token de acesso do Google fica apenas no computador do usuário, protegido pelo cofre de senhas do sistema operacional. Ele não é enviado ao desenvolvedor nem a terceiros.
  • Desconectar: o botão "Desconectar" revoga o acesso do app na conta Google e apaga o token do computador. O acesso também pode ser revogado em myaccount.google.com/permissions. Os arquivos na pasta MySecrets do Drive podem ser apagados pelo próprio usuário a qualquer momento.

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados obtidos do Google são usados exclusivamente para sincronizar o cofre do próprio usuário e não são usados para publicidade, vendidos ou transferidos a terceiros.

Extensão MySecrets Autofill

  • Credenciais (usuário, senha e código 2FA): obtidas do app MySecrets local somente no momento em que o usuário pede o preenchimento, e inseridas nos campos da página.
  • Endereço da aba atual: usado para encontrar os logins cadastrados para aquele site.
  • Token de pareamento: guardado no armazenamento local da extensão para autenticar a comunicação com o app.

A extensão se comunica apenas com o app MySecrets rodando no próprio computador do usuário, pelo endereço local 127.0.0.1. Clicar em "Desconectar" no popup (ou Ctrl+Shift+L) apaga o token de pareamento. Desinstalar a extensão remove todos os seus dados locais.

O que o MySecrets não faz

  • Não coleta histórico de navegação, conteúdo de páginas ou dados de uso.
  • Não usa rastreamento, anúncios ou análises.
  • Não vende nem transfere dados a terceiros.

Atualizações automáticas

O app consulta as releases públicas no GitHub para saber se há versão nova. Essa consulta não envia dados do cofre.
