Política de Privacidade — MySecrets Autofill

Última atualização: 29 de setembro de 2026

A extensão MySecrets Autofill preenche formulários de login usando credenciais armazenadas no app desktop MySecrets, instalado no computador do próprio usuário.

Dados que a extensão acessa

  • Credenciais (usuário, senha e código 2FA): obtidas do app MySecrets local somente no momento em que o usuário pede o preenchimento, e inseridas nos campos da página.
  • Endereço da aba atual: usado para encontrar os logins cadastrados para aquele site.
  • Token de pareamento: guardado no armazenamento local da extensão para autenticar a comunicação com o app.

Para onde os dados vão

A extensão se comunica apenas com o app MySecrets rodando no próprio computador do usuário, pelo endereço local 127.0.0.1. Nenhum dado é enviado a servidores externos, ao desenvolvedor ou a terceiros.

O que a extensão não faz

  • Não armazena senhas nem a senha mestra do cofre.
  • Não coleta histórico de navegação, conteúdo de páginas ou dados de uso.
  • Não usa rastreamento, anúncios ou análises.
  • Não vende nem transfere dados a terceiros.

Remoção dos dados

Clicar em "Desconectar" no popup (ou Ctrl+Shift+L) apaga o token de pareamento. Desinstalar a extensão remove todos os seus dados locais.
