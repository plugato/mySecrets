═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

    ❌ "Host not found"
       → make ext-integrate

    ❌ "Access denied"
       → Verificar Extension ID no manifest

    ❌ "App locked"
       → make dev (e desbloquear)

    ❌ Extensão não conecta
       → make ext-check (ver diagnóstico)

═══════════════════════════════════════════════════════════════
  FLUXO COMPLETO
═══════════════════════════════════════════════════════════════

    1. Usuário desbloqueia app → Cria .session
    2. Usuário vai para github.com/login
    3. Extensão detecta formulário
    4. Extensão solicita dados via Native Messaging
    5. Host verifica sessão (válida? app rodando?)
    6. Host lê secrets.enc e descriptografa
    7. Host filtra entradas para github.com
    8. Host retorna entradas
    9. Extensão preenche formulário!
